# Security Policy

## Reporting a vulnerability

Email **security@cliftonai.com** with details and reproduction steps. Please do not open a public issue for security reports.

We aim to acknowledge reports within **3 business days** and provide a fix or status update within **30 days** of acknowledgment.

## Scope

This repo holds public docs and a Claude Code plugin (config + a skill). The MCP service itself runs at `https://ai.cliftonapi.com/v1/mcp`.
